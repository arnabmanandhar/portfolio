FeaturedOpen Source · 2026

Anchor

Deterministic evaluation & tracing for RAG pipelines

An open-source library that answers the question you should ask before every deploy: did this change make my RAG pipeline better or worse? Retrieval is scored with pure math (Recall@k, MRR, nDCG, MAP), and faithfulness comes from a claim-level LLM judge that must cite the exact retrieved chunk behind each claim.

Every run is traced to SQLite with per-span latency, and a CLI diffs pipeline versions before you ship. Ships with pytest, GitHub Actions CI and a Streamlit dashboard, and runs fully offline when no API key is set.

NLP · RAG2026

Spashta (स्पष्ट)

News integrity reports for Nepali and English

Checks how a story is told: whether the headline matches the body, how sensational the wording is, whether claims are attributed, and whether independent outlets report the same facts. Every finding points to the words that produced it.

Hybrid retrieval fuses BM25, multilingual embeddings and a cross-language index, so Nepali, English and romanised Nepali coverage meet.

Legal AI · RAG2025

Nyaya AI

Explainable legal search over Nepal's constitution

A RAG search engine over Part 3 of the Constitution of Nepal. Compared BM25, SBERT and hybrid retrieval on Recall, MRR, nDCG and MAP, and chose hybrid for the best overall performance.

Fine-tuned three T5 variants and Mistral for legal QA, producing evidence-backed explanations grounded in retrieved clauses, with Nepali–English translation.

LLM Backend2026

TaskFlow RAG API

A cited, guarded knowledge-base API

A FastAPI service that retrieves section-aligned chunks from ChromaDB and answers only from that evidence, with document and section citations. Weak matches fall back to a clearly labelled offline tool instead of guessing.

Pydantic-validated output, injection-aware prompts, SSE streaming and structured JSON logs with timings and token usage.

I grew up in Lalitpur with two instincts that never quite separated: wanting to know how things work, and wanting to make something out of what I knew. That combination has put me inside a raag lesson, a robotics workshop, and, more recently, an open-source library that checks whether a RAG pipeline's answers are grounded in what it retrieved.

Most of my working hours go toward retrieval-augmented systems and one uncomfortable question: is this answer actually grounded in something real? I care about that more than is strictly reasonable, which is why I keep building evaluation tools nobody asked for.

I also spent years training in Indian classical music before I trained a neural network. The discipline required for both turned out to be closer than I expected.
